NEXT STEP — the watcher is not running yet.

Its pod stays in CreateContainerConfigError until a Secret named
{{ $fullname }} exists in this namespace. Create it with the cluster ID
and API key from {{ $appUrl }}/clusters (Clusters → New cluster):

  kubectl create secret generic {{ $fullname }} \
    --namespace {{ .Release.Namespace }} \
    --from-literal=cluster-id=<your-cluster-id> \
    --from-literal=api-key=<your-api-key>

The kubelet picks the Secret up by itself, usually within a minute — no
helm upgrade and no pod restart needed. Watch the pod reach Running:

  kubectl get pods -n {{ .Release.Namespace }} -w
{{- else }}

Wait for the watcher to become ready — the first informer sync has to
finish, which takes longer on a large cluster:

  kubectl rollout status deployment/{{ $fullname }}-watcher \
    -n {{ .Release.Namespace }} --timeout=5m
{{- end }}
